| --- | --- | --- |

## TutorBuddy positioning

TutorBuddy is the tutoring-focused whiteboard product name. The guidance below refers to the TutorBuddy experience and roadmap.

## Core positioning

Most tutoring platforms eventually hit a paywall that feels steep for a side hustle. To win, the tool must be **super cheap** while still delivering practical value:

1. **Zero-friction entry**: instant-link rooms with a permanent tutor “Home Room” link, plus student links that join without accounts.
2. **Geometry snapping**: ruler and compass that snap to grid or draw perfect 60° angles in two clicks.
3. **Freemium sweet spot**: keep all math tools free, but limit storage (e.g., charge $3–$5/month after five saved/exported boards).

## Killer tutor features

- **Student view lock**: tutor can work elsewhere while students are locked to a specific region or prompt.
- **PDF import**: lock a PDF page as an immovable background so students can’t accidentally move it.

## Pricing direction

- **Pay-as-you-go**: 50p unlocks a premium room for 24 hours.
- **Forever free solo tier**: keep 1-to-1 sessions free; charge for group classes or high-resolution recordings.

## Permissions model (tutor vs. student)

**Tutor can**

- Draw
- Type
- Upload
- Move/delete everything
- Use all tools

**Student can**

- Draw
- Type
- Use ruler / protractor / compass
- ❌ Cannot delete tutor content
- ❌ Cannot move uploaded worksheets

## Link model

- Tutor edit link: `/edit/:id`
- Student restricted link: `/student/:id`

## Build approach

You do not need to reinvent TutorBuddy from scratch. A practical path:

1. Fork Excalidraw (open source) as the TutorBuddy foundation.
2. Add role-based permissions and tool restrictions.
3. Generate two links (`/edit/:id` and `/student/:id`).
4. Read Excalidraw docs focusing on **Permissions** and **Collaboration**.

## Hosting options

**Option A (easiest for non-coders)**

- Use StackBlitz or CodeSandbox.
- Upload Excalidraw files.
- Edit/test in-browser, no installation needed.

**Option B (more permanent)**

- Use Netlify or Vercel for free hosting.
- One-click deploy → live URL.

## If Replit struggles to run

If Replit is slow or fails to start, try these lightweight alternatives first:

- **StackBlitz**: works well for quick previews without installing dependencies.
- **CodeSandbox**: reliable for static doc previews and simple edits.

If you still want to use Replit, consider:

1. Opening only the `dev-docs` folder instead of the entire monorepo.
2. Running just the docs site to reduce load:
   ```bash
   cd dev-docs
   yarn install
   yarn start
   ```
3. Disabling extra services or background processes in the Replit workspace.
